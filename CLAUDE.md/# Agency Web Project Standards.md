# Agency Web Project Standards

## Tech Stack
- Next.js (App Router), Tailwind CSS, TypeScript, Lucide React Icons.

## Development Rules
- Keep code modular and clean.
- Build UI elements using utility-first Tailwind CSS.
- Ensure all pages are fully responsive across mobile, tablet, and desktop screens.

## Commands
- Dev Server: `npm run dev`
- Build: `npm run build`
